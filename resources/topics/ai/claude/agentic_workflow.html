01

Captain, not coder

Act like an engineering director: build the systems, set the bar, trust the crew. Reviewing every diff by hand makes you the bottleneck. Your effort belongs at the two ends of a task.

02

The five stages

1 · Assemble the ship

A portable, keyboard-first setup you can drive anywhere — even your phone.

WezTerm → tmux → Neovim

  • Terminal keeps hands on the keyboard, so you stay in flow with no context-switch.
  • tmux sessions persist and reattach from any device.
  • Stay agent-agnostic — the model and harness landscape changes monthly.

2 · Ramp up the crew

Teach agents your conventions through memory files and skills, without burning tokens.

global memory → project memory → skills

  • Global memory stays tiny; it loads into every session's prompt.
  • Project memory grows by correction: fix a mistake, then store the lesson.
  • Skills use progressive disclosure — tokens are spent only when a skill is used. Vet them; stars are not quality.

3 · Work with one agent

Lock the requirements up front, then let it build.

voice in → plan visually → efficient CLI tools

  • Voice is about three times faster than typing; type only URLs and paths.
  • Plan visually and lock requirements before any code is written.
  • Benchmark your tools — agent-optimised CLIs can beat a wasteful MCP server (roughly 3x tokens, 2x latency).

4 · Validate by pipeline

Stop hand-reviewing every diff. Route work through a pipeline, then review by risk.

worktree → rebase → adversarial review → e2e + evidence → PR

  • The pipeline auto-fixes obvious issues and escalates product decisions to you.
  • It records evidence — a screenshot, video, or log — proving the change works.
  • Gate your review by risk: low-risk changes skip the diff, high-risk ones get read closely.

5 · Scale the crew

Run many agents in parallel; add an orchestrator when juggling costs more than the work.

git worktrees → overnight loops → first mate

  • Worktrees isolate parallel agents; automate their lifecycle.
  • Overnight loops suit verifiable or trusted objectives — set token and stop caps.
  • Add a first-mate orchestrator you talk to; it spins up tabs, runs the pipeline, and preps PRs.
The shift at the top

Once agents handle execution, you become the bottleneck. Move your energy to talking to users, reading the competitive landscape, and choosing direction.
